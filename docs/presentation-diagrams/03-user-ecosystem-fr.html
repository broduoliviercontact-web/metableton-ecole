Écosystème Utilisateur

Une plateforme pensée pour chaque acteur de l'école de musique — du visiteur curieux à l'administrateur.

Visiteur → Étudiant

  • • Catalogue public, pas de login
  • • Connexion Google pour s'inscrire
  • • Onboarding sans friction

Professeur

  • • Rôle attribué par l'admin
  • • Ses cours uniquement (ownership)
  • • Approuve/refuse les inscriptions
  • • Intégration Classroom

Admin

  • • Premier utilisateur = admin (bootstrap)
  • • Gère tous les utilisateurs et rôles
  • • Supervision globale des cours
  • • Protection dernier admin
