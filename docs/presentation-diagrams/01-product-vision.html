Metableton Ecole — Product Vision

Une plateforme web qui relie cours de musique, professeurs, étudiants et Google Classroom dans une expérience moderne.

For Students

  • • Google sign-in in one click
  • • Browse published courses
  • • Request enrollment
  • • Access Google Classroom

For Teachers

  • • Create and manage courses
  • • Review student requests
  • • Link Google Classroom
  • • Track enrolled students

For Schools

  • • Centralized user management
  • • Role-based access control
  • • Course catalog oversight
  • • Scalable architecture
