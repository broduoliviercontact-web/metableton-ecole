MVP Roadmap

Une base technique saine pour construire progressivement une vraie école de musique en ligne. 4 phases, du MVP à la communauté.

Phase 1: Done ✓

  • • Auth, catalog, enrollments
  • • 3 roles, RBAC middleware
  • • Session-based auth
  • • PostgreSQL schema

Phase 2: Active ⚡

  • • Classroom link validation
  • • Teacher dashboard
  • • Deep Classroom integration

Phase 3-4: Planned

  • • Learning experience layer
  • • Notifications & analytics
  • • Multi-school & community
