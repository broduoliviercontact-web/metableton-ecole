User Ecosystem

Une plateforme pensée pour chaque acteur de l'école de musique — du visiteur curieux à l'administrateur.

Visitor → Student

  • • Public catalog, no login needed
  • • Google sign-in to enroll
  • • Seamless onboarding

Teacher

  • • Role assigned by admin
  • • Own courses only (ownership)
  • • Approve/reject enrollments
  • • Classroom integration

Admin

  • • First user = admin (bootstrap)
  • • Manage all users & roles
  • • Global course oversight
  • • Last-admin protection
