Metableton Ecole — Student Enrollment Flow

Rôle: student — Parcours complet : login → catalogue → demande inscription → attente → approved/rejected → dashboard → Classroom

Enrollment State Machine

  • • none → pending (POST /enrollments)
  • • pending → approved (teacher/admin action)
  • • pending → rejected (teacher/admin action)
  • • rejected → pending (re-request via upsert)
  • • approved = terminal state

API Routes Used

  • • POST /api/enrollments (request)
  • • GET /api/enrollments/mine (my statuses)
  • • DELETE /api/enrollments/:id (cancel pending)
  • • GET /api/courses + /:id (browse)

Error States

  • • 401 — not authenticated (RequireAuth)
  • • 409 — ALREADY_PENDING / ALREADY_APPROVED
  • • 400 — course not published
  • • 404 — course/enrollment not found
  • • 409 — cancel non-pending enrollment
