Metableton Ecole — Visitor Discovery Flow

Rôle: visitor (non authentifié) — Parcours de découverte : landing → catalogue → détail cours → redirection auth si inscription demandée

Pages publiques (visitor)

  • • HomePage (/) — landing, présentation
  • • CatalogPage (/catalog) — tous les cours publiés
  • • CourseDetailPage (/catalog/:id) — fiche détaillée
  • • Toutes servies par PublicLayout
  • • Aucune auth requise pour la lecture

API routes publiques

  • • GET /api/courses — liste filtrée published
  • • GET /api/courses/:id — détail (published only)
  • • GET /api/health — health check
  • • Aucune auth middleware sur ces routes

Gating & redirects

  • • "Request Access" → vérifie session
  • • Non-auth → Google OAuth login
  • • Auth → dashboard role-based redirect
  • • RequireAuth wrapper sur /dashboard/*
  • • 401 si accès dashboard sans session
