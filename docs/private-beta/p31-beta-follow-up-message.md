# P-31 — Message de relance / follow-up

> **Version**: 2026-06-17  
> **Tags**: `mvp-demo-ready`, `private-beta`

---

## Contexte

Ce document contient les messages à envoyer **après que la personne a accepté de tester**.

---

## Message 1 — Relance douce si pas encore testé

### WhatsApp (2-3 jours après acceptance)

```
Salut [Prénom] 👋

Petite relance rapide : as-tu eu le temps de tester Metableton École ?

Si tu n'as pas encore eu le temps, pas de souci — il n'y a pas de deadline stricte.

Si tu as déjà testé, merci d'avance pour ton feedback !

Lien : https://metableton-ecole.vercel.app
```

### Email (2-3 jours après acceptance)

**Objet** : Petite relance pour le test Metableton École

**Corps** :

```
Salut [Prénom],

Petite relance pour le test Metableton École.

Si tu n'as pas encore eu le temps, pas de souci — il n'y a pas de deadline stricte.
Tu peux tester quand tu as 10-15 minutes à disposition.

Lien : https://metableton-ecole.vercel.app

Merci d'avance pour ton retour !
```

## Message 4 — Si un bug a été remonté et qu'on veut une précision

### WhatsApp

```
Salut [Prénom] 👋

Merci pour ton feedback concernant [détails du bug].

Pourrais-tu me préciser :
- Quel navigateur tu utilises ?
- Une description plus détaillée de ce qui ne fonctionne pas ?
- Est-ce que tu as une capture d'écran ou un screen recording ?

Merci d'avance !
```

### Email

**Objet** : Précision sur le bug que tu as remonté

**Corps** :

```
Salut [Prénom],

Merci pour ton feedback concernant [détails du bug].

Pourrais-tu me préciser :
1. Quel navigateur tu utilises ? (Chrome, Firefox, Safari, etc.)
2. Une description plus détaillée de ce qui ne fonctionne pas
3. Est-ce que tu as une capture d'écran ou un screen recording ?

Merci d'avance pour ton retour !
```
