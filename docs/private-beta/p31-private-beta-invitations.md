## Contexte

Metableton École est en phase de **bêta privée**. Ce document contient des messages prêts à envoyer pour inviter 3 à 5 testeurs.

> **Important** : Ce n'est pas une version finale. C'est un MVP testable pour valider le concept avant le lancement public.

---

## Profil 1 — Élève / Musicien / Producteur

### Version WhatsApp courte

```
Salut [Prénom] 👋

Je te contacte parce que tu es musicien/étudiant et que je travaille sur un nouveau projet pour aider les élèves à suivre des cours de musique en ligne avec Google Classroom.

C'est une bêta privée (pas un produit fini) — je cherche 3 à 5 testeurs pour valider le concept.

Temps requis : 10-15 min pour tester le workflow complet.

Si ça t'intéresse, voici le lien :
https://metableton-ecole.vercel.app

Merci d'avance !
```

### Version email plus propre

**Objet** : Teste mon nouveau projet Metableton École 🎵

**Corps** :

```
Salut [Prénom],

Je travaille sur Metableton École, une école de musique en ligne connectée à Google Classroom.

C'est actuellement en phase de bêta privée — je cherche 3 à 5 testeurs pour valider le concept avant un lancement public.

🔍 Ce qu'on test :
- Une école de musique en ligne avec cours structurés
- Des rôles étudiant / enseignant / admin
- Un système de demande d'inscription
- Une liaison avec Google Classroom (pas un LMS complet)

⏱️ Temps requis : 10 à 15 minutes pour tester le workflow complet

👉 Tu peux commencer ici : https://metableton-ecole.vercel.app

Note : Il s'agit d'un MVP testable, pas d'un produit fini. Tous les retours sont les bienvenus pour l'améliorer.

Merci pour ton temps !
[ton nom]
```

### Ton recommandé

- Humain, simple
- Pas de jargon startup
-expliquer que Google Classroom est un outil externe, pas le produit
- dire "MVP" ou "première version testable", pas "produit fini"

## À ne pas dire (à éviter)

| À NE PAS DIRE | Dire plutôt |
|---------------|-------------|
| "la plateforme est finie" | "un MVP testable" |
| "lancement officiel" | "bêta privée" |
| "inscris-toi définitivement" | "test le workflow" |
| "tout est automatisé" | "certains workflows sont manuels" |
| "Classroom est remplacé" | "Classroom est utilisé comme outil" |
| "paiement disponible" | "fonctionnalité à venir" |
| "contenus complets" | "contenus de démo disponibles" |
