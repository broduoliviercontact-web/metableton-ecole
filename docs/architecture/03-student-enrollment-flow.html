Metableton Ecole — Student Enrollment Flow

Complete student journey — browse catalog → request enrollment → teacher approval → Google Classroom access — with enrollment state machine

Enrollment State Machine

  • • none → pending (requestEnrollment)
  • • pending → approved (approveEnrollment)
  • • pending → rejected (rejectEnrollment)
  • • rejected → pending (re-request, retryable)
  • • approved = terminal (no further transitions)

API Routes Used

  • • GET /api/courses — public catalog
  • • GET /api/courses/:id — course detail
  • • POST /api/enrollments — request enrollment
  • • GET /api/enrollments/mine — student's list
  • • DELETE /api/enrollments/:id — cancel pending

Ownership & Permissions

  • • Student can only cancel their own requests
  • • Only pending enrollments can be canceled (409 otherwise)
  • • Teacher reviews enrollments for their own courses
  • • Admin can approve/reject any enrollment
