Metableton Ecole — Admin & Teacher Flow

Admin & teacher capabilities — course CRUD, enrollment review, user role management, Google Classroom linking, with role-based guards

Admin-Only Capabilities

  • • GET /api/admin/users — list all users
  • • PUT /api/admin/users/:id/role — change role
  • • GET /api/admin/courses — all courses overview
  • • Last-admin guard (409 if removing last admin)
  • • Admin bootstrap: 1st Google sign-in → admin

Teacher Capabilities

  • • GET /api/courses/manage — own courses (any status)
  • • POST /api/courses — create new course
  • • PUT /api/courses/:id — edit own course
  • • PUT /api/courses/:id/classroom — link Classroom
  • • Course validation: title, skillLevel, status

Shared (Admin + Teacher)

  • • GET /api/enrollments/pending — review queue
  • • POST enrollments/:id/approve — approve pending
  • • POST enrollments/:id/reject — reject pending
  • • Ownership check: teacher_id match or admin
  • • State guard: only pending → approve/reject
