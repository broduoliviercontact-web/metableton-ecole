Metableton Ecole — System Overview

High-level architecture of the online music school portal — React frontend, Express API, Supabase PostgreSQL, Google OAuth + Classroom

Frontend Stack

  • • React 19 + Vite 6
  • • Tailwind CSS 4
  • • React Router (public + dashboard)
  • • AuthContext + useAuth hook
  • • apiClient with credentials:include

Backend Stack

  • • Express 5 on Node.js
  • • 4 route modules (auth, courses, enrollments, admin)
  • • requireAuth + requireRole middleware
  • • express-session + connect-pg-simple
  • • Supabase JS SDK (service_role)

Data Layer

  • • Supabase PostgreSQL
  • • 3 tables: profiles, courses, enrollments
  • • 4 enum types (user_role, course_status, enrollment_status, skill_level)
  • • user_sessions (auto-created by connect-pg-simple)
