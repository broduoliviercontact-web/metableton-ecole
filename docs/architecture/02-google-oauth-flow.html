Metableton Ecole — Google OAuth Flow

Step-by-step Google OAuth 2.0 sign-in flow — consent screen → callback → profile upsert → session → role-based dashboard redirect

Auth Flow Summary

  • • GET /api/auth/google → Google consent
  • • Google redirects → callback with ?code=
  • • Exchange code for tokens + verify id_token
  • • findOrCreateGoogleProfile (upsert by sub)
  • • Session created → role-based dashboard redirect
  • • POST /api/auth/logout → destroy session

Google OAuth Config

  • • googleapis library (google.auth.OAuth2)
  • • Scopes: openid, profile, email
  • • access_type: offline (get refresh_token)
  • • prompt: consent (always show consent)
  • • id_token verified against audience

Session & Profile

  • • express-session + connect-pg-simple
  • • HTTP-only cookie (connect.sid)
  • • 7-day expiry · sameSite: lax/strict
  • • Admin bootstrap: 1st user → admin
  • • Returning users: role NEVER overwritten
