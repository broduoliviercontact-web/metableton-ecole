**Non-Functional Requirements that drive architecture:**

- **NFR-SEC-1 through 5:** Server-side session for every protected route, role verified per request, `GOOGLE_CLIENT_SECRET` server-only, OAuth tokens server-only, zero direct client-to-Supabase access
- **NFR-PERF-1 through 3:** Public pages <2s, dashboards <3s, Classroom API calls <5s with timeout
- **NFR-REL-1 and 2:** Graceful degradation when Supabase or Classroom API is down

### Technical Constraints & Dependencies

- **Google Classroom API is read-only in MVP** — GET `/v1/courses/{id}` for validation only; no course creation, no roster sync
- **Personal Gmail accounts** — OAuth consent screen type: External; Classroom API can only read courses where the authenticated user is already a teacher/student
- **JavaScript only, no TypeScript** — no type compilation step, simpler tooling
- **Monorepo structure** — `/client` (React+Vite+Tailwind), `/server` (Node+Express), `/supabase` (migrations)
- **HTTP-only session cookies** — no JWT in localStorage, session state server-side, client never sees tokens
- **Stated stack non-negotiable:** React, Vite, Tailwind, Node, Express, Supabase PostgreSQL

### Scale & Complexity

- **Primary domain:** Full-stack web application
- **Complexity level:** Low-to-medium
- **Estimated components:** 6 major areas — frontend, backend API, database, auth layer, external API integration, deployment config
- **Cross-cutting concerns:** Role-based access (every route/page), session lifecycle (OAuth token refresh), security boundary client↔server, external API resilience (Classroom availability)

### Cross-Cutting Concerns

1. **Auth everywhere** — Every protected route and API call verifies session + role. The middleware chain is the backbone of the backend.
2. **Security boundary** — Client never touches Supabase directly, never sees OAuth tokens, never receives `GOOGLE_CLIENT_SECRET`. All data access: Express → Supabase.
3. **Classroom API resilience** — Single external dependency. Needs timeout handling, user-friendly errors, graceful fallback.
4. **Role state consistency** — When admin changes a role, the affected user's session must reflect it on next request.
5. **Enrollment state machine** — Three states (pending/approved/rejected) with server-enforced transitions.

### Architectural Decisions This Stack Encodes

- **No SSR/SSG** — Pure client-side rendering. Express serves the API; Vite dev server (or built static files) serves the client.
- **No ORM** — Direct SQL via Supabase client or `pg` driver. Three tables, no ORM complexity warranted.
- **No state management library** — React Context for auth state and user profile. The app is small (3 dashboards, no complex shared state).
- **CSR + API separation** — Client fetches from Express; Express talks to Supabase and Google APIs.
- **Monorepo without tooling** — Two separate `package.json` files in `/client` and `/server`, root-level convenience scripts.
- **No Supabase Auth** — Google OAuth is handled entirely by the server. Supabase is a database only.
- **Client never touches Supabase** — All database access goes through Express. The client has no Supabase credentials.

### 2. Authentication & Security

**Google OAuth 2.0 — Authorization Code flow, fully server-side:**

1. Client redirects to `GET /api/auth/google`
2. Server generates OAuth URL (scopes: `openid profile email`) and redirects user to Google
3. Google redirects back to `GET /api/auth/google/callback` with authorization code
4. Server exchanges code for tokens via `google-auth-library` (uses `GOOGLE_CLIENT_SECRET`, never leaves server)
5. Server verifies id_token, extracts `sub`, `email`, `name`, `picture`
6. Server upserts profile in Supabase:
   - First user ever → `role = 'admin'`
   - Subsequent new users → `role = 'student'`
   - Returning users → update display name, email, avatar
7. Server creates session (`express-session`), stores `{ userId, role, googleTokens }`, sets HTTP-only cookie
8. Server redirects to role-appropriate dashboard

**Session:** `express-session` with `connect-pg-simple` backed by Supabase. Cookie: HTTP-only, SameSite=Lax, Secure in production. TTL: 7 days.

**Middleware chain:**
```
Request → sessionMiddleware → authMiddleware (401 if no session)
         → roleMiddleware('teacher', 'admin') (403 if wrong role)
         → routeHandler
```

**API routes — public (no auth):**
`GET /api/courses`, `GET /api/courses/:id`, `GET/POST /api/auth/google*`, `GET /api/auth/me`, `POST /api/auth/logout`

### 3. Google Classroom Integration (Validation-Only)

**Flow:** Teacher enters Classroom ID → server validates via `GET https://classroom.googleapis.com/v1/courses/{id}` with teacher's OAuth token from session → stores `classroom_id` and `classroom_url` on course if valid.

**Token refresh:** Before each Classroom API call, check expiry. Use refresh_token if expired. Update session with new tokens. If refresh fails, return 401.

**Classroom scope** (`classroom.courses.readonly`) requested incrementally when teacher first links a Classroom — not at initial sign-in.

## Implementation Patterns & Consistency Rules

### Naming Conventions

| Context | Convention | Example | Why |
|---|---|---|---|
| Database tables | `snake_case`, plural | `profiles`, `courses`, `enrollments` | PostgreSQL convention |
| Database columns | `snake_case` | `google_sub`, `display_name`, `teacher_id` | Matches SQL ecosystem |
| Enums | `snake_case` values | `'all_levels'`, `'in_progress'` | SQL-compatible |
| JavaScript variables | `camelCase` | `userId`, `displayName`, `classroomId` | JS/Node convention |
| JavaScript functions | `camelCase`, verb-first | `getUserById()`, `createCourse()` | Standard JS |
| React components | `PascalCase` | `StudentDashboard`, `CourseFormPage` | React convention |
| React files | `PascalCase.jsx` | `StudentDashboard.jsx` | Matches component name |
| Utility files | `camelCase.js` | `apiClient.js`, `courseService.js` | Not components |
| API routes | `kebab-case`, plural nouns | `/api/enrollments/pending` | REST convention |
| Route params | `:camelCase` | `/api/courses/:courseId` | Matches JS variable |
| CSS classes | Tailwind utilities only | No custom class names | Convention, not rule |

### Server-Side Patterns

**Express route handler pattern — every route follows this shape:**

```javascript
// server/src/routes/courses.js
import { Router } from 'express';
import { requireAuth } from '../middleware/auth.js';
import { requireRole } from '../middleware/role.js';
import * as courseService from '../services/courseService.js';

const router = Router();

// GET /api/courses — public catalog
router.get('/', async (req, res, next) => {
  try {
    const courses = await courseService.getPublishedCourses();
    res.json({ data: courses });
  } catch (err) {
    next(err);
  }
});

// POST /api/courses — create course (teacher, admin)
router.post('/', requireAuth, requireRole('teacher', 'admin'), async (req, res, next) => {
  try {
    const { title, description, skillLevel, coverImageUrl } = req.body;
    if (!title || !description) {
      return res.status(400).json({
        error: { code: 'VALIDATION_ERROR', message: 'Title and description are required.' }
      });
    }
    const course = await courseService.createCourse({
      teacherId: req.session.userId,
      title,
      description,
      skillLevel: skillLevel || 'all_levels',
      coverImageUrl: coverImageUrl || null,
    });
    res.status(201).json({ data: course });
  } catch (err) {
    next(err);
  }
});

// PUT /api/courses/:courseId — update course (owner or admin)
router.put('/:courseId', requireAuth, requireRole('teacher', 'admin'), async (req, res, next) => {
  try {
    const course = await courseService.getCourseById(req.params.courseId);
    if (!course) {
      return res.status(404).json({
        error: { code: 'NOT_FOUND', message: 'Course not found.' }
      });
    }
    // Ownership check: teacher must own the course, admin can edit any
    if (req.session.role !== 'admin' && course.teacher_id !== req.session.userId) {
      return res.status(403).json({
        error: { code: 'FORBIDDEN', message: 'You can only edit your own courses.' }
      });
    }
    const updated = await courseService.updateCourse(req.params.courseId, req.body);
    res.json({ data: updated });
  } catch (err) {
    next(err);
  }
});

export default router;
```

```javascript
import { supabase } from '../config/supabase.js';

export async function getPublishedCourses() {

    .from('courses')
    .insert({ teacher_id: teacherId, title, description, skill_level: skillLevel, cover_image_url: coverImageUrl })

export async function updateCourse(courseId, fields) {

  const dbFields = {};
  if (fields.title !== undefined) dbFields.title = fields.title;
  if (fields.description !== undefined) dbFields.description = fields.description;
  if (fields.skillLevel !== undefined) dbFields.skill_level = fields.skillLevel;
```

**Enrollment state machine — server-enforced transitions:**

```javascript
// server/src/services/enrollmentService.js
import { supabase } from '../config/supabase.js';

// Valid transitions:
//   none → pending   (student requests)
//   pending → approved (teacher/admin approves)
//   pending → rejected (teacher/admin rejects)
//   rejected → pending (student re-requests — retryable)

export async function requestEnrollment(studentId, courseId) {
  // Verify course exists and is published
  const { data: course } = await supabase
    .from('courses').select('id, status').eq('id', courseId).single();
  if (!course) throw Object.assign(new Error('Course not found'), { statusCode: 404 });
  if (course.status !== 'published') throw Object.assign(new Error('Course is not open for enrollment'), { statusCode: 400 });

  // Upsert: create new pending, or reset rejected back to pending
  const { data, error } = await supabase
    .from('enrollments')
    .upsert(
      { student_id: studentId, course_id: courseId, status: 'pending', updated_at: new Date().toISOString() },
      { onConflict: 'student_id,course_id' }
    )
    .select()
    .single();
  if (error) throw error;
  return data;
}

export async function approveEnrollment(enrollmentId, reviewerId) {
  return transitionEnrollment(enrollmentId, 'approved', reviewerId);
}

export async function rejectEnrollment(enrollmentId, reviewerId) {
  return transitionEnrollment(enrollmentId, 'rejected', reviewerId);
}

async function transitionEnrollment(enrollmentId, newStatus, reviewerId) {
  // Only allow transitioning from 'pending'
  const { data: enrollment } = await supabase
    .from('enrollments')
    .select('id, status, course_id')
    .eq('id', enrollmentId)
    .single();
  if (!enrollment) throw Object.assign(new Error('Enrollment not found'), { statusCode: 404 });
  if (enrollment.status !== 'pending') {
    throw Object.assign(new Error(`Cannot ${newStatus === 'approved' ? 'approve' : 'reject'} an enrollment that is already ${enrollment.status}`), { statusCode: 400 });
  }
  const { data, error } = await supabase
    .from('enrollments')
    .update({ status: newStatus, updated_at: new Date().toISOString() })
    .eq('id', enrollmentId)
    .select()
    .single();
  if (error) throw error;
  return data;
}

export async function getEnrollmentsForStudent(studentId) {
  const { data, error } = await supabase
    .from('enrollments')
    .select('*, courses(id, title, description, skill_level, classroom_id, classroom_url, profiles!courses_teacher_id_fkey(display_name))')
    .eq('student_id', studentId)
    .order('created_at', { ascending: false });
  if (error) throw error;
  return data;
}

export async function getPendingEnrollments(teacherId) {
  // Returns pending enrollments for courses owned by this teacher
  const { data, error } = await supabase
    .from('enrollments')
    .select('*, courses!inner(id, title, teacher_id), profiles!enrollments_student_id_fkey(display_name, email)')
    .eq('courses.teacher_id', teacherId)
    .eq('status', 'pending')
    .order('created_at', { ascending: true });
  if (error) throw error;
  return data;
}
```

```javascript
// server/src/services/profileService.js
import { supabase } from '../config/supabase.js';

export async function upsertProfile({ googleSub, email, displayName, avatarUrl }) {
  // Check if this is the very first user (admin bootstrap)
  const { count } = await supabase
    .from('profiles')
    .select('*', { count: 'exact', head: true });
  const isFirstUser = count === 0;

  const { data, error } = await supabase
    .from('profiles')
    .upsert(
      {
        google_sub: googleSub,
        email,
        display_name: displayName,
        avatar_url: avatarUrl,
        role: isFirstUser ? 'admin' : undefined, // undefined = use DB default ('student')
        updated_at: new Date().toISOString(),
      },
      { onConflict: 'google_sub' }
    )
    .select()
    .single();
  if (error) throw error;
  return data;
}

export async function getUserById(userId) {
  const { data, error } = await supabase
    .from('profiles')
    .select('id, email, display_name, avatar_url, role')
    .eq('id', userId)
    .single();
  if (error && error.code !== 'PGRST116') throw error;
  return data;
}

export async function getAllUsers() {
  const { data, error } = await supabase
    .from('profiles')
    .select('id, email, display_name, role, created_at')
    .order('created_at', { ascending: true });
  if (error) throw error;
  return data;
}

export async function changeUserRole(userId, newRole, adminId) {
  // Last-admin guard: prevent demoting the sole admin
  if (newRole !== 'admin') {
    const { count } = await supabase
      .from('profiles')
      .select('*', { count: 'exact', head: true })
      .eq('role', 'admin');
    const { data: targetUser } = await supabase
      .from('profiles')
      .select('role')
      .eq('id', userId)
      .single();
    if (count === 1 && targetUser && targetUser.role === 'admin') {
      throw Object.assign(new Error('Cannot remove the last admin. Promote another user to admin first.'), { statusCode: 400 });
    }
  }
  const { data, error } = await supabase
    .from('profiles')
    .update({ role: newRole, updated_at: new Date().toISOString() })
    .eq('id', userId)
    .select()
    .single();
  if (error) throw error;
  return data;
}
```

```javascript
// server/src/services/classroomService.js
import { google } from 'googleapis';

export async function validateClassroom(classroomId, accessToken) {
  // Extract ID if full URL was pasted
  const id = extractClassroomId(classroomId);

  const auth = new google.auth.OAuth2();
  auth.setCredentials({ access_token: accessToken });

  const classroom = google.classroom({ version: 'v1', auth });

  try {
    const response = await classroom.courses.get({ id });
    const course = response.data;
    return {
      valid: true,
      classroomId: course.id,
      classroomUrl: course.alternateLink || `https://classroom.google.com/c/${course.id}`,
      name: course.name,
    };
  } catch (err) {
    if (err.code === 404) {
      return { valid: false, reason: 'Classroom not found. Verify the ID.' };
    }
    if (err.code === 403) {
      return { valid: false, reason: 'You do not have access to this Classroom. Ensure you are a teacher in that class.' };
    }
    throw err; // Re-throw for global error handler (502 to client)
  }
}

function extractClassroomId(input) {
  // Accept raw ID ("123456789") or full URL
  const trimmed = input.trim();
  if (/^\d+$/.test(trimmed)) return trimmed;
  const match = trimmed.match(/\/c\/(\d+)/);
  if (match) return match[1];
  return trimmed; // Return as-is, let the API reject it
}
```

**Global error handler — last middleware in chain:**

```javascript
// server/src/middleware/errorHandler.js
export function errorHandler(err, req, res, _next) {
  console.error(`[${new Date().toISOString()}] ${req.method} ${req.path}:`, err.message);

  if (err.statusCode) {
    return res.status(err.statusCode).json({
      error: { code: mapStatusCodeToErrorCode(err.statusCode), message: err.message }
    });
  }

  // Supabase errors
  if (err.code && err.code.startsWith('PGRST')) {
    return res.status(400).json({
      error: { code: 'DATABASE_ERROR', message: 'A database error occurred.' }
    });
  }

  // Google API errors (re-thrown from classroomService)
  if (err.response && err.response.status) {
    return res.status(502).json({
      error: { code: 'CLASSROOM_API_ERROR', message: 'Google Classroom is temporarily unavailable. Try again in a few minutes.' }
    });
  }

  // Default 500
  res.status(500).json({
    error: { code: 'INTERNAL_ERROR', message: 'An unexpected error occurred.' }
  });
}

function mapStatusCodeToErrorCode(statusCode) {
  const map = { 400: 'VALIDATION_ERROR', 401: 'UNAUTHORIZED', 403: 'FORBIDDEN', 404: 'NOT_FOUND', 409: 'CONFLICT' };
  return map[statusCode] || 'INTERNAL_ERROR';
}
```

**API client wrapper — single fetch wrapper with error handling:**

```javascript
// client/src/api/client.js
const BASE_URL = import.meta.env.VITE_API_URL; // e.g., http://localhost:3001/api

export async function apiClient(path, options = {}) {
  const url = `${BASE_URL}${path}`;
  const config = {
    headers: { 'Content-Type': 'application/json', ...options.headers },
    credentials: 'include', // Send cookies (session)
    ...options,
  };

  const response = await fetch(url, config);

  if (!response.ok) {
    const body = await response.json().catch(() => ({}));
    const message = body.error?.message || `Request failed (${response.status})`;
    const error = new Error(message);
    error.status = response.status;
    error.code = body.error?.code;
    throw error;
  }

  return response.json();
}

// Convenience methods
export const api = {
  get: (path) => apiClient(path),
  post: (path, body) => apiClient(path, { method: 'POST', body: JSON.stringify(body) }),
  put: (path, body) => apiClient(path, { method: 'PUT', body: JSON.stringify(body) }),
  delete: (path) => apiClient(path, { method: 'DELETE' }),
};
```

### Error Handling Strategy

| Layer | Pattern | Behavior |
|---|---|---|
| **Service** | `throw error` | Let Supabase/Google errors propagate |
| **Route handler** | `try/catch` + `next(err)` | Catch in route, pass to error handler |
| **Global middleware** | `errorHandler` | Map errors to `{ error: { code, message } }` |
| **Client API** | Check `response.ok` | Throw with `{ message, status, code }` |
| **Page component** | `try/catch` in useEffect/event | Set `error` state, render `<ErrorMessage>` |
| **Auth errors (401)** | `AuthContext` handles | Set user null, redirect to login implicitly |

### Security Notes

1. **`GOOGLE_CLIENT_SECRET`** — only in `/server/.env`. The client `.env.example` has only `VITE_API_URL`. The client never needs `GOOGLE_CLIENT_ID` because the OAuth flow starts with a server redirect (`/api/auth/google`), not a client-side Google button with a client ID.

2. **Supabase `SERVICE_ROLE_KEY`** — bypasses RLS. Used only on the server. Never in client environment. The client cannot query Supabase directly.

3. **Session cookies** — HTTP-only means JavaScript cannot read them (XSS-resistant). SameSite=Lax prevents CSRF on GET requests. In production, `Secure` flag requires HTTPS.

4. **Role enforcement is server-side** — Client-side route guards are UX convenience only. The backend middleware (`requireAuth`, `requireRole`) is the real enforcement point. Every protected API route verifies session + role on every request.

5. **OAuth token storage** — Access and refresh tokens are stored in the server-side session, not in the database. If the session expires, tokens are lost and the user re-authenticates. Tokens are never exposed to the client.

6. **Input validation** — Routes validate required fields before passing to services. Supabase parameterized queries prevent SQL injection. Supabase client handles escaping.

## Architecture Summary

**What we're building:** A React SPA frontend that talks to an Express API backend. The backend talks to Supabase PostgreSQL and Google Classroom API. The client never talks to either directly.

**Data flow:**

```
Browser (React)
  → fetch (credentials: 'include')
    → Express API (session middleware → auth middleware → role middleware → route handler)
      → Supabase (service role key) — profiles, courses, enrollments
      → Google Classroom API (teacher's OAuth token) — validation only
```

**Key numbers:**
- 3 database tables (profiles, courses, enrollments)
- 4 enum types (user_role, course_status, enrollment_status, skill_level)
- 15 API routes (5 public, 10 protected)
- 10 React pages (3 public, 3 student, 3 teacher, 3 admin incl. shared, + 404)
- 2 middleware functions (requireAuth, requireRole)
- 4 services (profileService, courseService, enrollmentService, classroomService)
- No TypeScript, no ORM, no global state library, no monorepo tooling

**MVP boundaries respected:**
- Classroom API: GET only (validation), no course creation or roster sync
- No payments, no notifications, no mobile app
- Personal Gmail accounts (no Workspace domain)
- First login = admin bootstrap, subsequent = student default
- Moderated enrollment (request → pending → approve/reject)
- Rejected enrollments are retryable
- Admin can edit any course
- HTTP-only sessions, no tokens on client

**Architecture status: complete.**
